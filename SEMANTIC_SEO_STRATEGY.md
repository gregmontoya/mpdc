# Semantic Content Cluster Strategy (Koray Framework)

This document outlines the workflow for creating high-authority content clusters that dominate search intent and build topical authority.

## 1. Intent Detection (The Reddit/Community Heist)
*   **Source**: Extract live pain points from communities (e.g., r/Divorce_Men).
*   **Entity Extraction**: Identify specific legal, emotional, and financial "entities" (e.g., `DVPO`, `Monkey Branching`, `GLP-1 Weight Loss`).
*   **Gap Analysis**: Compare community questions with existing content to find a "Missing Node" in the Knowledge Graph.

## 2. Cluster Architecture
*   **Topical Hub**: Identify the "Pillar" article that broadly covers the topic.
*   **Spoke Articles**: Create 3-5 tactical, narrowly focused posts that answer the "next step" questions.
*   **Semantic Interlinking**: 
    *   Every Spoke links back to the Hub.
    *   Hub links down to the Spokes.
    *   Spokes link laterally to other Spokes using context-rich anchor text.

## 3. SEO Optimization Logic
*   **AEO Summary**: Every post must have a machine-readable summary (140-160 chars) for search engines and LLMs.
*   **Internal Link Styling**: Links must be visually distinct (Brand Color + Bold) to encourage user "dwell time" and page discovery.
*   **Automated Indexing**: Use Bing IndexNow for instant crawling after every deployment.

## 4. Brand & Conversion Loop
*   **Jargon Removal**: Natural language only (avoid internal "Module 1" terms).
*   **The Conversion Anchor**: Every article ends with a high-contrast CTA to the primary product/service (e.g., The Men's Divorce Mindset System).
