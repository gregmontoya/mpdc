# MPDC Brand Guidelines

## 1. Brand Colors

### Primary Palette
- **Deep Steel Green**
  - Hex: `#0b3b36`
  - Var: `--mpdc-green-primary`
  - Usage: Backgrounds, Primary Buttons, Headings

- **Sandstone Beige**
  - Hex: `#d1c8b8`
  - Var: `--mpdc-beige`
  - Usage: Backgrounds (Light), Secondary Text, Subtle Borders

- **Burnt Copper (Primary)**
  - Hex: `#B3542D`
  - Var: `--mpdc-copper`
  - Usage: Accents, CTAs, Highlights
- **High-Contrast Copper (Text)**
  - Hex: `#8B3A1C`
  - Var: `--mpdc-copper-text`
  - Usage: Text on light backgrounds, accessible badges

### Secondary Palette
- **Charcoal Slate**
  - Hex: `#1A1F24`
  - Var: `--mpdc-charcoal`
  - Usage: Body Text, Footer Backgrounds

## 2. Typography

### Primary Font (Headings)
- **Family:** Montserrat
- **Weights:** 700 (Bold), 900 (Black)
- **Usage:** Headlines, Section Titles, Navigation

### Body Font (Text)
- **Family:** Open Sans
- **Weights:** 400 (Regular), 600 (Semi-Bold)
- **Usage:** Paragraphs, List Items

### Accent Font (Logo/Special)
- **Family:** Bebas Neue
- **Usage:** Main Logo Text, Special Badges (Optional)

## 3. Logo
- **Style:** Stacked Text
- **Text:** "MEN'S POST" (Line 1) / "DIVORCE COACHING" (Line 2)
- **Font:** Bebas Neue / Montserrat
